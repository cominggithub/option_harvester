The discipline columns are vintage-side, because entry drift shows up there weeks before it reaches P&L. Bands mark where a rule version took effect.

Read the two lenses apart. A green cash week whose vintage column is empty means old trades paid off, not that the week was well traded; a red vintage week may still be running. “Ended” sums what that week’s sales have realized so far, so it under-reports weeks with positions still open. Compliance counts entry rules under the version in force at the time — see [Strategy](http://127.0.0.1:19210/short-call/strategy) for what each version changed, and [Cohorts](http://127.0.0.1:19210/short-call/cohorts) for the same trades cut by parameter instead of by date. Weeks use the same Mon–Sun convention as [Trans](http://127.0.0.1:19210/transactions), so totals reconcile.
